# Plan - Left It Here

## Goal

Ship a free offline note that shows where six household things were put, in type a grandparent can read.

## Approach

1. Confirm App Store Connect has no rejected app waiting.
2. Build Left It Here in Expo: six things, a written place, and a Look screen.
3. Run the full simulator regression on the Release binary for build 1.
4. Take three native screenshots, then upload that binary and submit it.

## Why this app

Picture lists, outing plans, dice, and dinner answers are already in this pipeline. Photo memory apps ask people to take a picture. This one is six huge labels and a place typed on the phone.
